Radiometer Backups — Privacy

Radiometer Backups is a private tool that stores daily infrastructure backup archives in the owner's Google Drive. It requests the Google Drive drive.file permission, which limits the tool to files and folders it creates or that the owner explicitly opens with it.

The archives contain radiometer measurements, object storage, service settings and credentials. They are kept in the owner's Drive account and are not shared by this tool. The server stores a Google OAuth refresh token to upload new archives and verify each upload. The owner can revoke access in Google Account settings and delete the archives from Drive.

For questions about this tool, use the support contact shown on Google's consent screen.
